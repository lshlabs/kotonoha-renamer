# Kotonoha Renamer 사용 안내

## 실행과 종료

ZIP의 `Kotonoha` 폴더 전체를 유지하고 `Kotonoha.exe`를 실행합니다. 기본 브라우저에서 `http://localhost:<빈 포트>/` 화면이 열립니다. HTML을 직접 열거나 주소만 입력하면 작업 권한이 없으므로 EXE를 통해 접속하세요. 주소의 접속 키는 초기 연결 후 화면 주소에서 제거합니다.

브라우저 탭을 닫아도 서버는 유지됩니다. EXE를 다시 실행하면 실행 중인 서버의 화면을 엽니다. 화면의 **프로그램 종료**로 서버를 종료합니다. 작업 중 종료는 진행 내용을 기록한 뒤 처리합니다.

Python·WebView2·Kotonoha 설치 마법사가 필요 없습니다. 관리자 권한은 Kotonoha 실행에 필요하지 않으나, 선택한 외부 Ollama 설치 프로그램이 요청할 수 있습니다.

## 작품 선택과 번역

**폴더 선택**은 Windows 폴더 대화상자를 엽니다. 경로를 붙여 넣고 **확인**을 눌러도 됩니다. 폴더 확인은 파일을 변경하거나 AI를 호출하지 않습니다.

모델과 번역 강도를 확인하고 **번역 시작**을 누릅니다. 원문·번역·완료 상태와 해당 제목을 공유하는 항목 수를 표시합니다. 제목 수는 파일 수와 다릅니다. 작업 단계·수신 제목 수·경과 시간·마지막 응답 시간을 표시합니다.

번역 셀을 직접 수정하면 같은 제목의 항목에 함께 적용합니다. 직접 수정한 제목은 전체 재번역에서 유지하고, 체크한 행에는 직접 수정한 제목도 포함할 수 있습니다. 강도는 1~10이며 다음 번역에 적용됩니다.

**표현 바꾸기**는 현재 한국어 번역에서 일치하는 텍스트만 치환하며 AI를 호출하지 않습니다. 제목을 체크하면 선택 범위에만, 선택하지 않으면 전체에 적용합니다. 여러 표현은 입력 순서대로 바꿉니다. 채택한 제목은 직접 수정으로 표시하여 전체 재번역에서 유지합니다. **새 번역안 사용**은 후보를 채택하고, **현재안 유지**는 기존 번역을 유지합니다. **직전 번역안 복귀**로 채택·수정을 되돌릴 수 있습니다.

## 적용과 복구

결과 폴더 이름과 최종 경로를 확인한 뒤 적용합니다. 원본 작품 폴더는 이름을 바꾸지 않고 그 안에 결과 폴더를 생성합니다. 내용은 같은 볼륨에서 이동하며 복사·삭제하지 않습니다. 복구 로그는 원본 작품 폴더에 남습니다.

이미 적용한 작품은 같은 원본 폴더를 다시 선택해 수정할 수 있습니다. 재적용은 기존 결과 폴더에서 달라진 이름만 변경하며, 확인 화면의 **수정한 이름으로 다시 적용**을 눌러 진행합니다. 다른 작업에서 만든 동명 폴더는 덮어쓰지 않습니다. 재적용 내역도 복구 로그에 기록됩니다.

폴더를 확인한 뒤 원본이 바뀌거나 이름 충돌이 생기면 적용을 거절합니다. 개별 파일·폴더 잠금으로 중단되면 **작업 기록**에서 남은 변경을 계속하거나 복구하세요. 복구 중 새로 추가된 사용자 파일은 삭제하지 않습니다.

기존 CLI의 저널 기반 복구 로그도 불러올 수 있습니다. 더 오래된 스크립트 로그는 [CLI 저장소](https://github.com/lshlabs/kotonoha-renamer-cli)에서 복구하세요. 포터블 이동 시 `data`의 외부 저널을 유지하고, 진행 중인 파일 작업이 있다면 먼저 정리하세요.

## 설정과 데이터

모델 목록은 SuperGemma로 구성하며 설치된 항목과 기본 모델에 체크를 표시합니다. 다운로드는 개별 모델 단위로 진행합니다. 기존 Ollama는 재사용하며, 새 모델은 다운로드 성공 후 기본으로 설정합니다. 권장 VRAM은 추정치입니다.

상단 **사용자 사전**에서 원문 제목의 표현을 드래그하고 원하는 한국어를 입력해 저장합니다. 저장한 표현은 다음 번역부터 모든 작품에서 참고합니다. 저장 성공 시 입력을 비우고, 실패 시 입력을 유지합니다.

`data`에는 모델 설정·선호·캐시·복구 저널·프로그램 로그를 저장합니다. Ollama 모델 자체는 Ollama가 관리하는 위치에 저장하며 Kotonoha 포터블에 자동으로 포함되지 않습니다. GUI와 CLI는 사용자 데이터 폴더를 별도로 사용합니다. 이전 설정을 옮길 때는 프로그램을 종료하고 필요한 설정 파일만 `data`에 복사하세요. 진행 중인 복구 기록은 원래 위치에서 먼저 정리하세요.

화면은 다크모드로 시작합니다. 상단 **라이트 모드 / 다크 모드** 버튼으로 전환하며, 선택은 같은 브라우저에 저장됩니다.
